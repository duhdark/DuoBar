# DuoBar 1.2.0

## What's New

- Refined Duo visuals inspired by the native iPhone design
- Redesigned rounded Wi-Fi indicator
- Refined Battery Ring and volume indicators
- Improved charging presentation and Battery Color Coding
- Display the current Wi-Fi network name
- Turn Wi-Fi on or off directly from DuoBar
- New Open on Hover option
- English, Simplified Chinese, and Traditional Chinese localization
- UI and reliability improvements

## Distribution

DuoBar 1.2.0 is signed with an Apple Developer ID and notarized by Apple for
safer, smoother installation.

- macOS 13 or later
- Apple Silicon and Intel
- Universal 2
- Free and open source
